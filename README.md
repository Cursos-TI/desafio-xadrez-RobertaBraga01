## 🧠 Descrição do Projeto

Este projeto tem como objetivo aplicar o uso das **estruturas de repetição** (`for`, `while` e `do-while`) na linguagem **C**, simulando a movimentação de três peças de xadrez no tabuleiro:  
- **Torre**  
- **Bispo**  
- **Rainha**

Cada peça usa uma estrutura de repetição diferente para representar seu movimento.

---

## 🎯 Objetivos

- Praticar o uso das estruturas de repetição em C.  
- Simular os movimentos básicos das principais peças de xadrez.  
- Demonstrar o comportamento de cada estrutura (`for`, `while`, `do-while`) de forma simples e visual.

---

## ⚙️ Estrutura do Programa

| Peça  | Estrutura utilizada | Movimento simulado | Direção exibida |
|-------|--------------------|--------------------|----------------|
| Torre  | `for` | 5 casas para a direita | “Direita” |
| Bispo  | `while` | 5 casas na diagonal superior direita | “Cima, Direita” |
| Rainha | `do-while` | 8 casas para a esquerda | “Esquerda” |
